# Resham-e-Mau (रेशम-ए-मऊ)

> **Luxury Handloom & Silk Weaving Legacy of Mau, Uttar Pradesh**

Resham-e-Mau is a luxury direct-to-consumer (D2C) saree storefront celebrating the centuries-old weaving traditions of Mau, UP. Featuring authentic pure Katan silk, antique Zari Banarasi weaves, Paithani silk, organza, and tissue sarees straight from master artisan looms.

---

## ✨ Features

- **Heritage Aesthetics**: Royal ivory (`#FAF6F0`), deep maroon (`#5A1827`), and antique gold zari (`#C59B27`) design language.
- **Curated Collections**: Katan Silk, Banarasi Brocade, Chanderi, Organza Tissue, Paithani, and Bridal Trousseau.
- **Artisan Transparency**: Origin verification, loom type tags (Handloom / Pit Loom / Jacquard), and fabric purity certificates.
- **Mobile-First Experience**: High-conversion bottom navigation bar, touch ergonomics, and responsive filters.
- **WhatsApp Direct Ordering**: Instant 1-click inquiry and order generation with pre-filled product details.
- **Interactive Cart & Quick View**: Dynamic cart drawer, free shipping progress bar, and saree drape preview modals.
- **Catalog Management**: Built-in admin catalog interface with local catalog API support.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite 6
- **Routing**: React Router DOM v7
- **Styling**: Tailwind CSS + Custom Heritage Color Tokens
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti
- **Typography**: Cormorant Garamond, Playfair Display, and Jost (Google Fonts)

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/abhinaveng04/resham-e-mau.git

# Navigate to the project directory
cd resham-e-mau

# Install dependencies
npm install

# Start the local development server
npm run dev
```

The application will be live at `http://localhost:5173`.

### Building for Production

```bash
npm run build
```

Previews the production build:
```bash
npm run preview
```
